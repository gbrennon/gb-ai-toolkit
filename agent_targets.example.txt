# Agent rule destination paths for `install-agent-rules`.
#
# Copy this file to your user config so it lives outside the source tree:
#
#     cp agent_targets.example.txt ~/.config/ai-toolkit/agent_targets.txt
#
# Then edit the paths below to match the agentic tools you have installed.
# Only the lines that do NOT start with `#` are used. Each line is the full
# path of a rules file that the tool reads (standard AGENTS.md/Markdown).
# Blank lines are ignored, and a leading `~` is expanded to your home dir.
#
# To install, run:  install-agent-rules
# (optionally:      install-agent-rules --targets-file /path/to/your/file)

# Cline — reads the shared cross-tool global AGENTS.md
~/.agents/AGENTS.md

# OpenCode — global rules file
~/.config/opencode/AGENTS.md

# Oh My Pi (omp) — global agent rules
~/.omp/agent/AGENTS.md

# Google AntiGravity — global rules file (standard AGENTS.md format)
~/.config/antigravity/AGENTS.md
